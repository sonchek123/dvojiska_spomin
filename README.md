# Ujemanje parov: dvojiško ↔ desetiško

Ta spletna igra omogoča učencem vadbo pretvarjanja med dvojiškimi in desetiškimi števili na zabaven način.

## Kako igrati

- Klikni dve kartici.
- Če predstavljata enako vrednost (ena dvojiško, druga desetiško), ostaneta odprti.
- Poišči vse pare!

## Zagon

Preprosto odpri `index.html` v svojem brskalniku **ali objavi kot GitHub Pages**.

## Objavi kot GitHub Pages

1. Ustvari repozitorij in naloži `index.html`
2. V nastavitvah (`Settings`) izberi zavihek **Pages**
3. Kot vir izberi **Deploy from a branch**
4. Shrani — GitHub bo ustvaril povezavo (npr. `https://tvojeime.github.io/ime-repozitorija`)
